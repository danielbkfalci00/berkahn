## Terminologia: Light Steel Frame vs. Steel Frame

A Berkahn trabalha com **Light Steel Frame (LSF)** — perfis leves de aço galvanizado formados a frio. **Steel Frame** (aço laminado pesado, perfis de grande porte) é um sistema construtivo diferente.

### Regras de uso
- Primeira menção: sempre "Light Steel Frame" por extenso
- Menções seguintes: pode usar "LSF" como abreviação
- NUNCA usar "Steel Frame" sozinho como sinônimo de LSF no corpo do texto
- Exceção: hashtags (#SteelFrame tem valor de alcance)
- Se o dado é específico do LSF, referenciar como "Light Steel Frame" ou "LSF"
- Se o título de um artigo usa "Steel Frame", pode reproduzir como está, mas no corpo manter "LSF"
