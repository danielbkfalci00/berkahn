# Docs — Berkahn Marketing Hub

Documentação organizada por workstream.

## Estrutura

| Pasta | Conteúdo |
|-------|----------|
| `brand/` | Identidade visual, logos, guia de design, assets para materiais |
| `blog/` | Artigos publicados (markdown), rascunhos, calendário de conteúdo |
| `apresentacoes/` | Materiais de apresentação (TAM, conteúdo de slides) |
| `site/` | Docs do site (admin, remodelação, SEO, conteúdo de páginas) |
| `legal/` | Política de privacidade, termos de uso |
| `orcamento/` | Imagens e pesquisa de orçamento/proposta |
| `integracoes/` | Google Sheets, APIs externas |
| `imagens/` | Banco de imagens organizado por tipo |

## Imagens (`imagens/`)

| Subpasta | O que guardar |
|----------|--------------|
| `projetos/` | Fotos de casas prontas, obras em andamento |
| `equipe/` | Fotos da equipe Berkahn |
| `backgrounds/` | Texturas, fundos para materiais |
| `pecas-criadas/` | Flyers, cards, materiais prontos |
| `lsf-tecnico/` | Diagramas, layers, detalhes técnicos de LSF |
| `parceiros/` | Logos de parceiros (Knauf, Eternit, etc.) |
| `referencia/` | Screenshots de concorrentes, inspirações |

## Pastas legadas (migração em andamento)

As pastas originais (`Artigos_Berkahn/`, `Identidade Visual/`, `LGPD/`, etc.) ainda existem. O conteúdo foi copiado para a nova estrutura. Quando a migração estiver confirmada, as pastas legadas serão removidas.
